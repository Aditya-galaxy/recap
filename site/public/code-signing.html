Privacy and code signing

How releases are built

Every release is built by GitHub Actions from the public source code at github.com/Aditya-galaxy/recap, together with the programs bundled with it (FFmpeg, whisper.cpp and llama.cpp, each built from their published source). Nothing built on a personal computer is ever published.

  • macOS: not notarized by Apple yet, so macOS asks you to confirm the first time you open it.
  • Windows, Microsoft Store (coming soon): the Store version is signed by Microsoft.
  • Windows, direct download: not code-signed yet, so Windows asks you to confirm the first time you open it. PCs with Smart App Control turned on only run signed apps; on those, use the Microsoft Store version once it's out.
  • Linux: AppImage and .deb; Linux doesn't need code signing to run them.

Team roles

  • Committers and reviewers: Aditya-galaxy
  • Approvers: Aditya-galaxy

Every release is approved by hand. Changes from other contributors are reviewed before they're merged.

Privacy

Recap records, transcribes and edits on your computer. Your recordings, transcripts, guides and reports are never sent anywhere unless you choose to share them. The app only contacts other systems in these cases:

  • Update check: every few hours it asks GitHub for the latest release number. Nothing about you or your recordings is sent.
  • Transcription model: on first run it downloads the Whisper speech model from Hugging Face.
  • On-device AI (optional): only if you choose "polish", it downloads a language model from Hugging Face once.
  • Feedback: only when you write and send feedback, your message is sent to recap.kronagent.dev.
  • Links you open, such as a GitHub issue you file, open in your browser.
